# dogi · 测测你是哪种修勾

一个「测测你是 X」类型的性格测试小站。24 道亲密关系场景题，六个维度计分，余弦相似度匹配到 24 种狗狗。

纯静态单文件，零依赖，直接部署在 GitHub Pages 上。

## 这是什么

假设有一个人，和你的关系很近。每道题描述「ta 做了什么」，你从三个反应里选最接近你的一个。

- **六个维度**：外向性、亲和性、情绪稳定性、尽责性、开放性、支配性
- **计分**：每题三个选项分别计 `+1` / `0` / `-1`。`+1` 和 `-1` 在 A、C 两个位置交替出现，「看情况」的 `0` 分固定放中间，所以没法靠选项位置猜规律
- **匹配**：六维原始分（每维 -4 ~ +4）归一化后，与 24 种狗的理想向量算**余弦相似度**，取最高的一只作主类型，第二高的作「影子」

## 为什么用余弦而不是直线距离

用欧氏距离时，人答完题的六维向量天然挤在原点附近，向量幅度大的类型几乎永远匹配不上——实测最冷的一只只占 0.8%，最热的一只啃掉 36.9%。余弦只比较六维的「形状」不比幅度，分布才拉得开。

目前的蒙特卡洛结果（2 万份随机答卷）：24 种狗命中率 **2.3% ~ 10.7%**，均匀基线 4.2%。没有一只抽不到，也没有一只一家独大。

## 本地预览

```bash
python3 -m http.server 8822
# 打开 http://127.0.0.1:8822
```

直接双击 `index.html` 也能看，但「分享」按钮的剪贴板功能在 `file://` 下会被浏览器拦掉。

## 改内容

打开 `index.html`，搜索 `数据（由` 那一行。下面的 `BREEDS` / `QUIZ` / `DIMS` 是纯数据，照着改即可，逻辑代码不用动。

数据是从生成 Excel 的脚本自动导出的，改 Excel 那边重跑脚本会同步过来。
